# Online Game Template

Base para jogos online web — começando com um jogo estilo `.io` e preparada para evoluir para multiplayer massivo.

**Stack:** Phaser 4 · TypeScript · Tiled · Pixel art (nearest-neighbor / pixel-perfect) · Cliente web-first · Servidor autoritativo em Node.js

> Status: **fundação / planejamento.** Nenhum código de gameplay ainda.
